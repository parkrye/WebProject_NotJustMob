## 소개

키보토스에 사는 평범한 학생(모브) 한 명을 직접 만들어, 마감 없이 하루하루를 보내는 오픈월드 RPG입니다. 화면에는 글자가 없고 그림과 아이콘으로만 안내합니다.

## 조작법

| 하는 일 | 키보드 | 터치 |
|---|---|---|
| 이동 | <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> / 방향키 | 조이스틱 |
| 달리기 | <kbd>Shift</kbd> | 조이스틱을 끝까지 |
| 말 걸기 · 활동 · 결정 | <kbd>Space</kbd> / <kbd>Enter</kbd> | 탭 |
| 닫기 · 건너뛰기 | <kbd>Esc</kbd> | 닫기 단추 |
| 태블릿 | <kbd>Tab</kbd> | 태블릿 단추 |
| 가방 | <kbd>I</kbd> | 가방 단추 |
| 모모톡 | <kbd>T</kbd> | 모모톡 단추 |
| 지도 | <kbd>M</kbd> | 지도 단추 |
| 탈것 타고 내리기 | <kbd>V</kbd> | – |
| 시간 기다리기 | <kbd>Z</kbd> | 하늘 시계 탭 |
| 방 꾸미기(내 방에서) | <kbd>R</kbd> | 방 꾸미기 단추 |
| 감정 표현 | <kbd>1</kbd>–<kbd>0</kbd> | – |
| 도움말 | <kbd>H</kbd> | ? 단추 |

- 마우스: 단추를 누르면 열리고, 단추 위에 잠깐 올려 두면 그 단추가 하는 일을 그림으로 보여 줍니다. 터치 화면에서는 길게 누르면 같은 그림이 뜹니다.
- 화면 오른쪽 아래에는 지금 누를 수 있는 키가 그림으로 나옵니다.

## 콘텐츠

- **나만의 학생**: 학원을 고르고 체형·머리·얼굴·옷을 파츠로 조합해 만듭니다. 성향(사교성·호기심·위험성·활동성)과 나이도 정합니다.
- **키보토스 오픈월드**: 아비도스·게헨나·트리니티·밀레니엄·백귀야행·산해경·붉은겨울·발키리·SRT·아리우스 등 학원별 지역과 맵.
- **흐르는 하루**: 하루는 실제 48분. 아침·오후·저녁·밤이 바뀌고 날씨와 계절이 있습니다.
- **퀘스트**: 일상 의뢰부터 지역·학원·동아리 이야기, 사이드 스토리, 메인 스토리까지.
- **사람들**: 각자 생활하는 학생들과 만나 친해지고 모모톡을 주고받습니다.
- **탈것**: 킥보드·스케이트보드·자전거·스쿠터 등으로 빠르게 이동합니다.
- **미니게임**: 레이싱·리버시 등 고전 게임풍의 부가 미니게임.
- **내 방**: 모은 가구로 방을 꾸밉니다.
